# IBKR → דוח מס רווחי הון (טפסים 1322 / 1325)

כלי עזר אישי מקומי (Next.js + TypeScript) שממיר דוח פעילות שנתי מ-Interactive
Brokers (IBKR Activity Statement, CSV) לנתונים מוכנים לדיווח רווחי הון לרשות
המסים בישראל — טופס 1325 (פירוט עסקאות כרונולוגי) וטופס 1322 (סיכום שנתי).

**זהו כלי עזר לארגון נתונים בלבד — אינו תחליף לבדיקת רואה חשבון לפני הגשה
בפועל.** ראו גם "הערות ומגבלות" בסוף הקובץ.

## הרצה מקומית

דרישות: Node.js 20+‎.

```bash
npm install
npm run dev
```

האפליקציה תרוץ בכתובת http://localhost:3000

פקודות נוספות:

```bash
npm run build   # build לפרודקשן
npm test        # הרצת כל הטסטים (vitest)
npm run lint     # ESLint
```

## איפה הנתונים נשמרים

כל הנתונים הפיננסיים (קבצי IBKR, עסקאות, תוצאות חישוב) נשמרים **מקומית
בדפדפן בלבד** (IndexedDB, דרך Dexie — ראו `lib/persistence/`). שום מידע פיננסי
אישי אינו נשלח לשרת חיצוני כלשהו.

**החריג היחיד**: כדי לחשב רווח/הפסד בש"ח, האפליקציה מבקשת מהשרת המקומי שלה
(`app/api/boi-rate/route.ts`) לשלוף שערי חליפין רשמיים (שער יציג USD/ILS) מה-
API הציבורי של בנק ישראל. זו הקריאה החיצונית היחידה בכל האפליקציה. התוצאות
נשמרות ב-cache מקומי בקובץ `data/boi-rate-cache.json` (לא נכלל ב-git) כדי
שאותו תאריך לא יישלף פעמיים.

## איך זה עובד

1. **העלאה** (`/`) — גוררים או בוחרים קובץ/י CSV של IBKR (אפשר כמה קבצים,
   למשל שני דוחות חצי-שנתיים). הקבצים מפוענחים ונשמרים מקומית, עם הסרת
   כפילויות לפי TransactionID.
2. **תצוגה מקדימה** (`/preview`) — כל העסקאות המאוחדות, עם אפשרות לסמן עסקה
   כלא-כלולה בחישוב, בחירת שנת מס, והזנת הפסד הון מועבר משנים קודמות (אם יש).
3. **תוצאות** (`/results`) — לאחר "חשב תוצאות": התאמת FIFO בין קניות ומכירות
   (כולל אופציות, שורט, פקיעה ומימוש), שליפת שערי חליפין, וחישוב הרווח/הפסד
   בש"ח. שלושה טאבים (1325 / 1322 / דיבידנדים וריבית) + ייצוא לאקסל.

## מבנה הקוד

| מודול | תפקיד |
|---|---|
| `lib/ibkr-parser/` | פענוח קובצי ה-CSV הרב-סקשן של IBKR (עמיד לשינויי עמודות בין גרסאות/שפות חשבון), מיזוג ודה-דופ של כמה קבצים |
| `lib/fifo-engine/` | מנוע התאמת FIFO — כולל שורט, אופציות (calls/puts, spreads), פקיעה ומימוש/הצמדה |
| `lib/exchange-rate/` | שליפת שערי בנק ישראל, cache מקומי, נפילה לשער הקודם בסופ"ש/חג, override ידני |
| `lib/forms/` | בניית טבלת 1325 וסיכום 1322 מתוך תוצאות ה-FIFO ושערי החליפין |
| `lib/xlsx-export/` | ייצוא לאקסל (exceljs) — 3 גיליונות, RTL, עיצוב מספרים ומטבע |
| `lib/persistence/` | סכימת IndexedDB (Dexie) ושכבת גישה לנתונים |
| `config/tax-parameters.ts` | פרמטרים המתעדכנים מדי שנה — ראו סעיף הבא |

כל מודול לוגי מכוסה בטסטים תחת `__tests__/` (`npm test`), כולל: FIFO רגיל,
FIFO עם שורט, פקיעת אופציה חסרת ערך, מימוש אופציה (העברת בסיס עלות למניה),
נפילת שער בסופ"ש, ומיזוג שני קבצי חצי-שנה עם דה-דופ. יש גם טסט end-to-end
(`__tests__/e2e-smoke.test.ts`) שמריץ קובץ IBKR לדוגמה (`__tests__/fixtures/`)
דרך כל הצינור עד לטבלת 1325 וסיכום 1322.

## עדכון פרמטרים שנתיים (חשוב!)

רשות המסים מעדכנת מדי שנה את סף הפטור מהגשה ואת מבנה הטפסים. **יש לעדכן
את `config/tax-parameters.ts`** בתחילת כל שנת מס חדשה — זהו המקום היחיד
בקוד שבו מוגדרים המספרים האלה (הם אינם מקודדים קשיח בשום מקום אחר):

```ts
export const TAX_YEAR_CONFIG: Record<number, TaxYearParameters> = {
  2025: {
    realCapitalGainsTaxRatePct: 25,
    securitiesProceedsExemptionFromFilingILS: 375_000,
    generalFilingObligationCeilingILS: 717_000,
  },
  // הוסיפו כאן שורה לשנה החדשה, עם הערכים המעודכנים מאתר gov.il:
  // 2026: { realCapitalGainsTaxRatePct: 25, securitiesProceedsExemptionFromFilingILS: ..., generalFilingObligationCeilingILS: ... },
};
```

נכון לכתיבת הקוד, ערכי 2025 מבוססים על חיפוש ברשת (לא על ה-PDF הרשמי עצמו,
שלא היה נגיש בסביבת הפיתוח) — **יש לוודא אותם מול gov.il** לפני הסתמכות
בפועל.

## הערות ומגבלות

- **שערי בנק ישראל**: ה-API ההיסטורי האמיתי של בנק ישראל (SDMX) נמצא ב-
  `edge.boi.gov.il` (ולא ב-`GetExchangeRate?asOf=` כפי שניתן להניח בטעות —
  אותו endpoint ישן מחזיר רק את השער הנוכחי, ללא תמיכה בתאריך היסטורי).
  הכתובת מוגדרת כקבוע יחיד ב-`config/tax-parameters.ts` (`BOI_API_CONFIG`) —
  אם בנק ישראל ישנה את המבנה, זה המקום היחיד שצריך לעדכן. אם הקריאות
  מתחילות להיכשל, כדאי לנסות גם את המארח החלופי `edge.boi.org.il`.
- **מבנה טופס 1325**: סדר וכותרות העמודות בקוד (`lib/forms/form-1325.ts`)
  אומתו מול מימוש ייחוס עבודה (open-source) שנבנה לאותה מטרה — אך לא מול
  ה-PDF הרשמי העדכני ישירות. מומלץ להשוות מול הטופס העדכני מ-gov.il לפני
  הגשה.
- **מבנה טופס 1322**: המבנה בקוד (`lib/forms/form-1322.ts`) עוקב אחר
  המבנה העקרוני המוכר (רווח/הפסד ריאלי, קיזוז והעברת הפסדים, דיבידנד/ריבית
  וניכוי מס זר) — סדר השדות המדויק בטופס הרשמי לא אומת ישירות. יש להשוות
  מול ה-PDF העדכני.
- אופציות: הכפלה סטנדרטית (multiplier) של 100 מניות לחוזה מיושמת כברירת
  מחדל (`lib/fifo-engine/options.ts`) — נכון לרוב חוזי האופציות על מניות/ETF
  אמריקאיים.
